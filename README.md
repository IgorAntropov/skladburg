# Skladburg

SaaS для складского учёта в стиле изометрического симулятора: склады, двор, доки, машины и люди — в живом мире вместо таблиц. Сейчас проект — демо, которое работает прямо в браузере.

## Требования

- Node 24 LTS (версия указана в `.nvmrc`).
- pnpm через Corepack: он входит в Node 24, а версию pnpm Corepack берёт из поля `packageManager` сам. В Node 25 и новее Corepack ставится отдельно: `npm i -g corepack`.

## Запуск

```bash
nvm use
corepack enable
pnpm install
pnpm lint
```

`pnpm install` сам ставит git-хук pre-commit: перед коммитом проверяются изменённые файлы.

## Скрипты

| Команда          | Что делает                                                                    |
| ---------------- | ----------------------------------------------------------------------------- |
| `pnpm lint`      | проверка типов, ESLint и поиск комментариев в остальных файлах                |
| `pnpm lint:fix`  | автоисправление ESLint                                                        |
| `pnpm typecheck` | проверка типов по всему монорепозиторию                                       |
